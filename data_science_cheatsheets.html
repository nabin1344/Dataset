📊 Data Science Cheat Sheet

The 20% of functions that cover 80% of real-world usage

NumPy
import numpy as np
⚡ Arrays are faster than lists — vectorize everything. Avoid Python loops over NumPy arrays.
Array Creation
From list / zeros / ones / range
np.array([1,2,3]) np.zeros((3,4)) # 3×4 zeros np.ones((2,3)) # 2×3 ones np.arange(0,10,2) # [0,2,4,6,8] np.linspace(0,1,5) # 5 evenly spaced np.random.randn(3,3) # normal dist
Shape & dtype inspection
a.shape # (rows, cols) a.ndim # number of dimensions a.dtype # int64, float32 … a.astype(float) # cast to float a.reshape(6,1) # new shape (same data) a.flatten() # always returns copy
Indexing & Slicing
Basic indexing
a[0] # first row a[1, 2] # row 1, col 2 a[0:3, 1:4] # slice rows 0-2, cols 1-3 a[:, 0] # all rows, col 0 a[-1] # last row
Boolean & fancy indexing
a[a > 0] # all positive values a[(a > 0) & (a < 5)] idx = [0, 2, 4] a[idx] # rows 0, 2, 4 np.where(a > 0, a, 0) # replace negatives
Math & Stats
Aggregate functions
a.sum() a.sum(axis=0) # col sums a.mean() a.std() a.var() a.min() a.max() a.argmin() # index of min a.cumsum() # cumulative sum
Linear algebra essentials
np.dot(A, B) # matrix multiply A @ B # same, Python 3.5+ np.linalg.inv(A) np.linalg.eig(A) # eigenvalues/vectors np.linalg.norm(v) # L2 norm
Pandas
import pandas as pd
🐼 DataFrames are the workbench — think in columns, not loops. Use vectorized operations whenever possible.
Creating & Loading
Read data
pd.read_csv('file.csv') pd.read_csv('f.csv', index_col=0, parse_dates=['date']) pd.read_excel('file.xlsx', sheet_name='Sheet1') pd.read_json('file.json') pd.read_sql(query, connection)
Quick inspection
df.head(5) df.tail(3) df.info() # dtypes + nulls df.describe() # numeric stats df.value_counts() df.shape df.columns df.dtypes
Selection & Filtering
loc / iloc
df.loc[0:5, ['a', 'b']] # label-based df.iloc[0:5, 0:2] # position-based df.loc[df['col'] > 0] # filter rows df['col'].isin(['a','b'])
Missing values
df.isnull().sum() # count NaN df.dropna(subset=['col']) df.fillna(0) # fill with 0 df['col'].fillna(df['col'].median())
GroupBy — the workhorse
df.groupby('cat')['val'].mean() df.groupby('cat').agg( n=('id','count'), avg=('val','mean') ) df.pivot_table(values='v', index='r', columns='c', aggfunc='mean')
Merge & join
pd.merge(df1, df2, on='id', how='left') pd.concat([df1,df2], ignore_index=True) # how: 'inner','left','right','outer'
Apply & map
df['col'].apply(lambda x: x*2) df.apply(np.mean, axis=0) df['cat'].map({'a':1, 'b':2}) pd.get_dummies(df['col'])
Matplotlib
import matplotlib.pyplot as plt
📈 Always end with plt.tight_layout() then plt.show(). Prefer the fig, ax pattern over plt.* for full control.
Core Template
The fig/ax pattern — use this every time
fig, ax = plt.subplots(figsize=(8, 5)) ax.plot(x, y, color='steelblue', label='line') ax.set_title('Title') ax.set_xlabel('X') ; ax.set_ylabel('Y') ax.legend() plt.tight_layout() plt.show() # or plt.savefig('fig.png', dpi=150)
Plot Types
Line, scatter, bar, histogram
ax.plot(x, y) # line ax.scatter(x, y, c=z) # scatter + color ax.bar(cats, vals) # vertical bar ax.barh(cats, vals) # horizontal bar ax.hist(data, bins=30) # histogram
Multiple subplots
fig, axes = plt.subplots(2,3, figsize=(12,6)) # axes[0,0], axes[0,1] … fig.suptitle('Dashboard', y=1.02) plt.subplots_adjust(hspace=0.4)
Styling Shortcuts
Limits, ticks, grid, annotations
ax.set_xlim(0, 100) ax.set_xticks([0,25,50,75,100]) ax.grid(True, linestyle='--', alpha=0.5) ax.axhline(y=0, color='red') ax.annotate('Peak', xy=(x,y), xytext=(x+1,y+2), arrowprops=dict(arrowstyle='->'))
Style themes & colors
plt.style.use('seaborn-v0_8-whitegrid') plt.style.use('ggplot') # color: name, hex, or (r,g,b) ax.plot(x, y, color='#E74C3C') # colormap for arrays: ax.scatter(x, y, c=z, cmap='viridis')
Seaborn
import seaborn as sns
🎨 Built on matplotlib — pass a DataFrame + column names. Set theme once at the top: sns.set_theme(style="whitegrid").
Distribution
histplot / kdeplot / boxplot / violinplot
sns.histplot(df, x='age', hue='gender', kde=True) sns.kdeplot(df, x='score', fill=True) sns.boxplot(df, x='cat', y='val') sns.violinplot(df, x='cat', y='val', inner='box')
heatmap — correlation matrix
corr = df.corr(numeric_only=True) sns.heatmap(corr, annot=True, fmt='.2f', cmap='coolwarm', vmin=-1, vmax=1, square=True, linewidths=0.5)
Relationship
scatterplot / lineplot / regplot
sns.scatterplot(df, x='x', y='y', hue='cat', size='val') sns.lineplot(df, x='date', y='val', hue='group') sns.regplot(df, x='x', y='y') # scatter + fit
Categorical
barplot / countplot / stripplot
sns.barplot(df, x='cat', y='val', errorbar='sd') sns.countplot(df, x='cat', hue='group') sns.stripplot(df, x='cat', y='val', jitter=True)
FacetGrid — multi-panel powerhouse
g = sns.FacetGrid(df, col='group', hue='cat', height=4) g.map_dataframe(sns.scatterplot, x='x', y='y') g.add_legend() # Or the high-level pair-grid: sns.pairplot(df, hue='target', diag_kind='kde')
Seaborn Quick Wins
hue / size / style — free third dimension, always
sns.scatterplot(df, x='income', y='spend', hue='region', # color encodes category size='age', # marker size encodes numeric style='gender', # marker style encodes another cat palette='tab10') # consistent palette # Save after any seaborn call: plt.savefig('plot.png', dpi=150, bbox_inches='tight')
